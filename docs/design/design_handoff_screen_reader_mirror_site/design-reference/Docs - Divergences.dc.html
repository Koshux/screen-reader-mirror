Where the mirror and screen readers disagree

A living list. The mirror is not a screen reader and will differ from one in places. Each known difference is written down with what each side says, why, and whether it is a bug, a profile gap, or intended. If yours is not here, report it.

Report one

From a row to an issue

  1. 1

    Click "Report divergence" under the row

    Any row marked differs has it. In the CLI, the session report has a report link per differing row.

  2. 2

    Review the sheet

    It lists exactly what goes in: the mirror's row, the screen reader's row, profile, source, versions (engine, browser, screen reader), the element's selector, and about 20 lines of HTML around it. The page URL is not included unless you tick it. Edit anything.

    If it is already known, the sheet says so and links the entry above instead of opening a new issue.

  3. 3

    Send

    Opens a pre-filled GitHub issue in a new tab. Nothing leaves the machine until you press Submit there.

What happens next

  • Triaged into one of the four kinds within a week.
  • Bugs get a golden fixture reproducing the HTML, then the fix. The fixture stays forever.
  • Profile gaps are grouped per screen reader and land with that profile.
  • Every entry above links its issue.
