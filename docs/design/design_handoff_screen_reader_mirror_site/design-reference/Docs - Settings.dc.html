Every switch, and what it changes

The cog in the extension and bookmarklet panels opens one sheet. Here is each control, its default, what it does to the list, and where the value lives. Nothing here is synced or sent; everything stays in this browser profile.

Reset

"Reset all settings" at the bottom of the sheet returns every value above to its default and forgets the pairing. It asks once.
