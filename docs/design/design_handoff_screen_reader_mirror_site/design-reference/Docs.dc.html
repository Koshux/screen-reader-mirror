Documentation

What it is, and where to start

A screen reader simulator developers can read. The engine walks a page and returns the flat reading order a screen reader would traverse: role, name, level, flags. It is not a screen reader and does not replace testing with one; it tells you what to fix before you test, and shows you the difference after.

Why

The gap the mirror fills

  • Linters check rules. A <span class="h2"> styled as a heading passes every rule and is plain text to a screen reader.
  • Devtools show the accessibility tree, one node at a time. A screen reader does not read a tree; it reads a flat order.
  • A real screen reader is the truth, and it is sound. It does not point back at the markup that produced a word.

The mirror shows the flat order, in words, beside the page, with each row pointing at its element. Then it stands beside the real thing and marks every row where they disagree.

Shape

One engine, many hosts

                 packages/core  (npm + CDN, no network, pure)
   DOM / AX tree ──▶  roles & names · reading order · flags · live regions  ──▶ InterpretationNode[]
                         ▲              ▲              ▲             ▲
                   extension          cli           web          your app

Every host is a thin adapter: it gets a tree from somewhere and shows the engine's result. The hard part lives in one tested place, and the same output appears in a side panel, a terminal, a CI report, or your own code.

Vocabulary

Eight words the rest of the docs use

TermMeans Reading orderThe sequence a screen reader moves through: DOM order of the composed tree. CSS reordering is ignored on purpose. Role, nameThe computed WAI-ARIA role and the accessible name (AccName 1.2). "button" and "Save". FlagA condition worth checking on a row: unnamed, missingAlt, unreachable. Not a score. NoteText from the mirror explaining a flag. Never part of the speech. SourceWhere the tree came from: DOM walk, AX tree, pasted HTML, URL. ProfileWhose words: Generic, NVDA, JAWS, VoiceOver. ModeHow you are moving: read all, Tab, headings, landmarks, table cells, forms mode, live regions. CaptureWhat a real screen reader said, from the local bridge or an imported log, aligned row by row.
