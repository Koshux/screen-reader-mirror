Commands, flags, exit codes

Capture

--capture, and listen

FlagDoesDefault --capture bridgeSubscribe to the local bridge, print rows as the screen reader speaks, write a session report on Ctrl+C. Implies --headed. Exits 1 if any row differs.off --capture <log file>Compare against a saved speech log or session report instead of a live bridge.— --port <n>Bridge port, both for listen and --capture.7331 
npx screen-reader-mirror listen [--port 7331]

● NVDA 2025.1 detected (speech viewer stream)
  Bridge on  ws://localhost:7331
  Pair code  4 8 2 1
  Subscribers 0 · Utterances 0

listen watches for NVDA (Speech Viewer stream), JAWS (speech history) and VoiceOver (captions). It prints a new pair code after three wrong attempts, and keeps waiting if no screen reader is running. Only speech text and timestamps pass through it.

Exit codes

0, 1, 2

CodeMeans0Clean, or no gates asked for.1A gate failed: flag, snapshot diff, or divergence.2Could not read the page: navigation, timeout, missing browser. Not an accessibility result.
