Nothing leaves the machine

The engine makes no network calls. Every host keeps that promise in its own way. This page says what each one stores, what it can see, and what it never does.

Engine

Pure computation

  • linearize() is a function over the element you pass it. No fetch, no XHR, no WebSocket, no image beacons. Enforced by a lint rule and a commit hook that fail the build if any network API appears in packages/core.
  • Two dependencies, both permissively licensed and both pure: dom-accessibility-api, aria-query.
  • The output contains no live DOM references, so it can cross a boundary without carrying a page with it.

Never

What none of this does

  • No analytics, no telemetry, no crash reporting, no cookies on this site.
  • No account, no API key, no sign-in anywhere.
  • The divergence report opens a GitHub issue you review and submit yourself; the page URL is off by default.
  • Logs you import stay in the tab and are gone when it closes.

Safe for regulated, EU and internal pages. If something here stops being true, it is a bug; please report it.
