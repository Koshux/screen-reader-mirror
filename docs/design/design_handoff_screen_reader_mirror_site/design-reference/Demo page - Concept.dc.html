Read speech as HTML

A linter passes the page. A screen reader log is a wall of words. The mirror puts the reading order next to the markup, so any developer can see what a blind user gets, fix it, and run again. For dev teams, agencies and public bodies working to ADA, Section 508, the European Accessibility Act and WCAG 2.2.
