Compared with other tools

Linters, devtools, screen readers, simulators

Each tool is good at its job. None gives a developer the flat reading order of pasted HTML, in the browser, with nothing installed and nothing sent. One screen per tool, same sample page throughout.

1Real screen readers

NVDA, JAWS, VoiceOver

The ground truth and the final test.

  • ShowsSpeech, live, with each product's own phrasing and quirks.
  • MissesNothing. But the output is sound, not a list to diff or paste into an issue, and learning one takes days.
  • With the mirrorFind the obvious mistakes first, then confirm here. Where they disagree, report the divergence.

2Linters

axe, WAVE, Lighthouse

Rule checkers. Fast, well known, easy to put in CI.

  • ShowsViolations against rules, with severity and a fix hint.
  • MissesReading order and what will be announced. A styled span acting as a heading passes clean.
  • With the mirrorKeep the linter. The mirror shows the order and the words the rules cannot.

4Browser devtools

The accessibility tree

  • With the mirrorWhen a row looks odd, open the node here to see how the browser computed it.

6Test library

Virtual Screen Reader

Guidepup. A simulator for unit tests, driven from code. Closest in spirit.

  • ShowsSpoken phrases as strings your tests can assert on.
  • MissesA page a developer can open and paste into. No visual mirror beside the output.
  • With the mirrorUse it in unit tests; use the mirror while building and reviewing.

7Earlier text views

Fangs, Site Unseen

The idea has been tried before.

  • ShowsFangs rendered a page as screen reader text in Firefox. Site Unseen hides the page and lets you explore it blind.
  • MissesFangs stopped in 2010. Site Unseen is built for empathy and training, not a list to fix from.
  • With the mirrorThe mirror picks up where Fangs left off: kept current, with flags and JSON.

8Where it fits

screen-reader-mirror

Paste HTML or run on any page. See the flat reading order with flags. Copy it. Run it in CI.

  • ShowsOne flat list in reading order: role, name, level, flags. Beside the rendered page, each row pointing at its element.
  • MissesThe sound. It is not a screen reader and says so. Shadow DOM, iframes and live regions are not traversed yet.
  • With the othersLinter for rules, mirror for order and words, real screen reader to confirm.
